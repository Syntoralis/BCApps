# Essai gratuit — Syntoralis FIFO Logistic

Profitez de **30 jours d'essai gratuit** sur le Microsoft Marketplace pour évaluer Syntoralis FIFO Logistic dans votre environnement Business Central.

{% include marketplace-link.html label="Démarrer l'essai" placement="trial-hero-fr" %}

## Ce que comprend l'essai

- Accès complet à toutes les fonctionnalités pendant 30 jours.
- Support technique par e-mail pendant l'essai.
- Documentation complète (FR/EN) et guides de paramétrage.
- Aucune carte bancaire requise pour démarrer.

## Démarrage en 5 étapes

1. **Installer** l'extension depuis le [Microsoft Marketplace]({{ site.marketplace_url }}).
2. **Activer** la licence d'essai dans Business Central (Extensions → Syntoralis FIFO Logistic → Activer).
3. **Paramétrer** les emplacements concernés ([guide de paramétrage](./setup.html)).
4. **Tester** sur un prélèvement pilote (entrepôt ou inventaire).
5. **Valider** les résultats (rotation, lots, numéros de série, FEFO).

## Liste de vérification (checklist)

- [ ] Extension installée et activée.
- [ ] Au moins un emplacement configuré en FIFO.
- [ ] Prélèvement pilote créé et validé.
- [ ] Lots / numéros de série affectés correctement.
- [ ] FEFO vérifié sur articles avec expiration.

## Problèmes fréquents

- **Aucune couche FIFO** : vérifier que les réceptions ont bien été enregistrées (le moteur ne gère pas les réceptions).
- **Prélèvement non FIFO** : l'emplacement n'est pas configuré pour FIFO — voir [Paramétrage](./setup.html).
- **Lots non affectés** : vérifier le suivi par lot sur la fiche article.
